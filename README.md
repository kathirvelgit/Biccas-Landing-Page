# 🌐 Biccas Landing Page - React

A modern and responsive **Biccas Landing Page** built using **React.js and CSS**, based on a Figma design. The project uses reusable React components for the Navbar, Hero, Features, About, Pricing, Testimonials, and Footer sections.

---

## 🚀 Features

- 🎨 Figma-based UI design
- ⚛️ Built with React.js
- 📱 Responsive design for desktop, tablet, and mobile
- 🧩 Reusable React components
- 🧭 Navigation bar with Login and Sign Up buttons
- 🦸 Hero section with call-to-action buttons
- ⭐ Features section
- 📊 About section
- 💰 Pricing section
- 💬 Testimonials section
- 🔻 Footer section
- 🖼️ Custom images and assets
- 🎯 Clean and organized CSS
